### 配置入口与默认值

下表除消息合并窗口外，均相对于 `channels["openclaw-weixin"]`。

| 配置项 | 当前默认值 | 需要覆盖的状态 |
| --- | --- | --- |
| `promptBindOwner` | `false` | 未配置、`false`、`true`；开启后分别选本人和他人 |
| `verifyPin` | `false` | 未配置、`false`、`true` |
| `errorNotices` | `false` | 未配置、`false`、`true` |
| `replyProgressMessages` | `true` | 未配置、`false`、`true`，并与失败提示交叉验证 |

| `mediaDownload.timeoutMs` | `0`，不限总时长 | 未配置、`0`、正数 |
| `mediaDownload.idleTimeoutMs` | `30000` 毫秒 | 默认值、自定义正数 |
| `quoteCache.mediaStorage.mode` | `managed` | `managed`、`inbound`、`custom` |
| `messages.inbound.byChannel["openclaw-weixin"]` | 未配置时回退到全局 `messages.inbound.debounceMs`；均未配置则关闭 | 未配置、`0`、正数 |
| `acctwebBaseUrl` / `acctwebProxy` | 默认实名源站 / 直连 | 默认值、指定源站或代理；有条件时验证账号级覆盖 |

例如，分别开启、关闭、移除 PIN 配置：

```bash
openclaw config set 'channels["openclaw-weixin"].verifyPin' true --strict-json
openclaw config set 'channels["openclaw-weixin"].verifyPin' false --strict-json
openclaw config unset 'channels["openclaw-weixin"].verifyPin'
```

以上三条是不同测试状态，按当前测试项执行对应的一条。其他布尔开关可使用相同方式设置。登录入口：

```bash
openclaw channels login --channel openclaw-weixin
```
